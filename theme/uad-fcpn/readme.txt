=== UAD FCPN ===
Contributors: UAD FCPN
Requires at least: 6.4
Requires PHP: 7.4
Stable tag: 1.0.0

Tema institucional para la Unidad de Administración Desconcentrada de la FCPN - UMSA.

== Funciones incluidas ==

* Portada institucional adaptable a computadoras, tabletas y teléfonos.
* Sección Documentos administrable desde el panel de WordPress.
* Categorías documentales y gestiones/años.
* Campos para número, fecha, palabras clave y archivo PDF.
* Búsqueda por título, descripción, contenido, número, palabras clave, categoría y gestión.
* Filtros sin recarga mediante AJAX y alternativa funcional sin JavaScript.
* Paginación para bibliotecas extensas.
* Comunicados mediante las entradas normales de WordPress.
* Datos de contacto editables en Apariencia > Personalizar.
* Logotipo personalizado y menú de WordPress.

== Instalación ==

1. En WordPress, abre Apariencia > Temas > Añadir nuevo > Subir tema.
2. Selecciona el archivo uad-fcpn.zip.
3. Pulsa Instalar ahora y luego Activar.
4. Abre Apariencia > Personalizar > Datos institucionales UAD.
5. Añade el logotipo, correo, teléfono, dirección y horario.
6. Abre Documentos > Añadir documento para publicar el primer PDF.

Al activar el tema se crean estas categorías: Instructivos, Circulares, Comunicados, Reglamentos, Normativas y Otros documentos. También se crea la gestión del año actual.

== Cómo publicar un documento ==

1. Documentos > Añadir documento.
2. Usa el título para el nombre oficial del documento.
3. Usa el extracto para el resumen corto que aparecerá en los resultados.
4. Usa el editor principal para la descripción completa o información adicional.
5. Completa número/código, fecha y palabras clave.
6. Pulsa Seleccionar o subir PDF.
7. Marca una categoría y una gestión.
8. Publica.

== Comunicados ==

La portada muestra las dos entradas más recientes de WordPress. Crea comunicados desde Entradas > Añadir entrada.

== Solución rápida ==

Si una ficha individual muestra un error 404, abre Ajustes > Enlaces permanentes y pulsa Guardar cambios una vez.
